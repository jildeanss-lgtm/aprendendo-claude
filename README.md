# aprendendo-claude

Olá! Eu sou o **Jildean** e este é o meu projeto para aprender a usar o **Claude Code** e a programar, começando do zero.

## 🎯 Objetivo

- Aprender a usar o Claude Code
- Entender o básico de programação
- Aprender a usar o Git e o GitHub

## 🗺️ Meus passos de aprendizado

- [x] Passo 1: Melhorar o README do projeto
- [ ] Passo 2: Criar uma página web sobre mim (HTML)
- [ ] Passo 3: Deixar a página bonita (CSS)
- [ ] Passo 4: Criar um programinha simples (jogo de adivinhar o número)
- [ ] Passo 5: Fazer mudanças por conta própria

## 📚 O que já aprendi

- **README**: o arquivo que apresenta o projeto ("leia-me")
- **Markdown**: um jeito de escrever texto com símbolos (`#`, `**`, `-`) que mudam a aparência
- **Git**: guarda o histórico de versões dos arquivos
- **Commit**: uma "foto" do projeto com uma mensagem explicando o que mudou
- **Branch**: uma "linha do tempo paralela" para testar coisas sem estragar a versão principal
